# WriteGuard project media

These are deterministic, editable sources for the Devpost project gallery and demo video. The PNG exports are the upload-ready assets.

| Asset | Source dimensions | Intended use |
|---|---:|---|
| `writeguard-thumbnail` | 1500×1000 (3:2) | Devpost gallery thumbnail and video title card |
| `unsafe-vs-guarded` | 1600×900 (16:9) | Core problem/outcome proof |
| `product-journey` | 1600×900 (16:9) | Product journey and design-time/runtime boundary |
| `verification-receipt` | 1600×900 (16:9) | Verified levels, limitations, and next step |

All claims are deliberately scoped to the documented simulation and verification evidence. Do not crop away `simulated`, `passed with limitations`, or `not run` labels.

Before publication, review the final PNGs at 100% size and confirm that the Devpost preview does not crop essential text. Keep repository ownership, local paths, terminal history, notifications, environment variables, and credentials out of any additional screenshots or video footage.
